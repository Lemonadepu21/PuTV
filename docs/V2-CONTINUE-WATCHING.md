# V2 第三阶段：首页继续观看

本阶段已人工验收通过。复用第二阶段已经验收的档案历史、分集进度、离线缓存与同步；不新增数据库表、API、依赖或环境变量。

## 展示和续播规则

- 首页 Hero 下方显示「继续观看」，推荐片单随后展示。关闭首页推荐仍保留继续观看；分类、搜索和直播页面不加入此分区。
- 最多展示最近观看的 12 项，使用当前账号、当前档案的同步缓存。没有符合条件的记录时隐藏分区。
- 横版封面、片名、集数、已看时间及进度条。没有图片或加载失败时保留固定比例占位；支持深浅主题。
- 分集进度优先于历史摘要；记录的片源 URL 跟随续播链接，避免其他设备同短 ID 的片源配置串源。链接不固定时间点，播放器继续使用原有的播放前同步与进度恢复流程。
- 与原播放器一致：观看超过 10 秒才提供该集续播；标记完成或距离片尾不超过 2 秒的电影不再出现。剧集继续下一集，跳过已完成的集数；全部已看完时隐藏。只依据已有集数，不额外查询影视元数据。
- 历史面板仍可查看全部记录、删除和清空；对应首页卡片实时更新。切换账号或档案沿用已有身份隔离和页面重载。
- 两端更新沿用既有同步节奏；在线首页通常在下一次同步后反映其他设备的更改。离线时展示本机已有缓存，不宣称跨设备实时一致。
