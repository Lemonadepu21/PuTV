# V1 实施记录

本次基于 LibreTV `deb72fa`（版本 2.21.0）开始，保留完整上游历史。开发与验收实例使用 8081；已有 LibreTV 8080 服务不参与 PuTv 构建或重启。

## 代码勘察

- 路由：`/` 负责推荐和 URL 参数 `?s=` 搜索；`/watch` 点播；`/live` 直播；`/about` 项目信息。当前没有独立电影、剧集、动漫页面。
- 推荐：`douban-section.tsx` 按用户设置选择豆瓣 / Bangumi / 热榜，原有过滤与切换保留。首页分类入口应复用这些能力，不添加空页面。
- 主题：`globals.css` 的 RGB CSS 变量由 Tailwind 映射；`theme.tsx` 管理三态主题；`layout.tsx` 内联脚本保证首屏主题。
- 状态：React Query 管理请求；Zustand + localStorage 管理设置；Dexie + IndexedDB 管理观看数据。
- 详情：`detail-modal.tsx` 与原有 Drawer、焦点管理继续保留。推荐条目当前点击触发搜索，之后从搜索结果进入详情；后续 Hero 不得新增元数据请求伪造详情。
- 播放：ArtPlayer + hls.js；触屏隐藏策略在 `control-hide.ts`，点播与直播共用。自动旋转目前未启用；点播启用迷你进度条。
